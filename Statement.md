# Project Statement: Shopping Cart GUI Application

## Problem Statement

With the rapid growth of digital commerce and retail management systems, there is a growing need for intuitive applications that simplify the process of managing purchases and calculating costs. Traditional manual calculations can be time-consuming and prone to errors, especially when handling multiple products and quantities.

This project addresses that challenge by providing a graphical Shopping Cart Application that enables users to add products, manage quantities, calculate totals automatically, and simulate a checkout process through an interactive and user-friendly interface. The application demonstrates the fundamental concepts behind modern e-commerce and point-of-sale (POS) systems while remaining lightweight and easy to use.

---

## Scope of the Project

The scope of this project is limited to a desktop-based GUI application developed using Python and Tkinter.

### The application includes:

* Adding products with custom names and prices.
* Automatic quantity management for duplicate items.
* Real-time subtotal and total cost calculations.
* Item quantity increment and decrement controls.
* Individual item removal functionality.
* Cart clearing functionality with confirmation.
* Checkout simulation with order summary generation.
* Input validation and user-friendly error handling.
* Responsive graphical user interface with interactive controls.

### The application does not include:

* User authentication and account management.
* Database integration or cloud storage.
* Online payment gateway integration.
* Inventory management system.
* Product image support.
* Tax calculation and discount management.
* Multi-user functionality.
* Persistent storage of purchase history.

## High-Level Features

### 🛒 Product Management

* Add products with custom names and prices.
* Automatically merge duplicate products by increasing quantity.

### 🔢 Quantity Control

* Increase or decrease item quantities dynamically.
* Automatic item removal when quantity reaches zero.

### 💰 Billing System

* Real-time subtotal calculations.
* Automatic total price computation.
* Dynamic item count tracking.

### ✅ Input Validation

* Prevents empty product names.
* Validates price inputs.
* Restricts invalid or negative values.
* Displays informative error messages.

### 🧾 Checkout Module

* Generates a complete order summary.
* Displays item quantities and subtotals.
* Simulates order confirmation and placement.

### 🎨 Modern User Interface

* Clean and intuitive design.
* Interactive buttons with hover effects.
* Scrollable cart display.
* Responsive layout for improved user experience.
